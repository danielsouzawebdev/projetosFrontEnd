Pet Shop — Landing Page

HTML CSS Bootstrap JS leve

Uma página institucional completa de uma loja fictícia, a "Amigo Fiel Pet Shop" — a mesma dupla Cachorro/Gato que apareceu nos materiais de POO e de introdução ao front-end, agora virando conteúdo de verdade numa página.

Pré-requisitos

Os módulos de HTML Básico, CSS Básico e Bootstrap Básico. Este tutorial não reexplica o que é um seletor CSS ou a classe container — só usa.

Passo 1 — Estrutura de pastas

Crie uma pasta chamada petshop e, dentro dela, três arquivos:

petshop/
├── index.html
├── style.css
└── script.js

Mantenha os três no mesmo nível (nenhum dentro de subpasta) — assim os caminhos relativos dos próximos passos funcionam sem ajuste.

Passo 2 — HTML base + Bootstrap

Abra index.html e escreva a estrutura base, já ligando o Bootstrap via CDN e os seus próprios arquivos:

index.html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Amigo Fiel Pet Shop</title>

  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <link href="style.css" rel="stylesheet">
</head>
<body>

  <!-- o resto dos passos entra aqui -->

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  <script src="script.js"></script>
</body>
</html>
Ordem importa

Seu style.css vem depois do Bootstrap no <head> — assim, se você precisar sobrescrever alguma cor do Bootstrap, seu CSS vence. E script.js vem depois do bundle do Bootstrap no fim do <body>.

Abra o arquivo no navegador (ou use a extensão Live Server) para conferir que carregou sem erro antes de continuar — a página vai estar em branco, e está certo.

Passo 4 — Hero

Logo depois da </nav>, adicione a seção de abertura:

index.html
<header class="hero-petshop text-white text-center py-5">
  <div class="container py-5">
    <h1 class="display-4 fw-bold">Seu melhor amigo merece o melhor cuidado</h1>
    <p class="lead">Banho, tosa, consultas veterinárias e hospedagem — tudo num só lugar.</p>
    <a href="#contato" class="btn btn-light btn-lg mt-3">Agende um horário</a>
  </div>
</header>

Agora o CSS próprio — abra style.css e crie o fundo em degradê que o Bootstrap sozinho não tem:

style.css
.hero-petshop {
  background: linear-gradient(135deg, #2E7D5B, #1572B6);
}

É assim que HTML, Bootstrap e CSS próprio convivem: a estrutura e o espaçamento vêm de classes do Bootstrap (py-5, display-4, btn-lg); o visual que o Bootstrap não oferece pronto (esse degradê específico) vem do seu style.css.

Passo 7 — Formulário de contato

index.html
<section id="contato" class="py-5">
  <div class="container" style="max-width: 600px;">
    <h2 class="text-center mb-5">Agende um horário</h2>

    <form id="formContato">
      <div class="mb-3">
        <label for="nomeTutor" class="form-label">Seu nome</label>
        <input type="text" class="form-control" id="nomeTutor" required>
      </div>
      <div class="mb-3">
        <label for="nomePet" class="form-label">Nome do pet</label>
        <input type="text" class="form-control" id="nomePet" required>
      </div>
      <div class="mb-3">
        <label for="servicoDesejado" class="form-label">Serviço desejado</label>
        <select class="form-select" id="servicoDesejado">
          <option>Banho e Tosa</option>
          <option>Consulta Veterinária</option>
          <option>Hospedagem</option>
        </select>
      </div>
      <button type="submit" class="btn btn-success w-100">Enviar pedido</button>
    </form>

    <div id="mensagemSucesso" class="alert alert-success mt-3 d-none">
      Pedido enviado! Entraremos em contato em breve.
    </div>
  </div>
</section>

Agora o toque de JavaScript — o formulário não tem backend de verdade, então vamos simular o envio, mostrando a mensagem de sucesso e escondendo o formulário:

script.js
const form = document.querySelector("#formContato");
const mensagemSucesso = document.querySelector("#mensagemSucesso");

form.addEventListener("submit", (evento) => {
  evento.preventDefault();

  const nomePet = document.querySelector("#nomePet").value;

  mensagemSucesso.textContent = `Pedido enviado! Em breve entraremos em contato sobre o atendimento de ${nomePet}.`;
  mensagemSucesso.classList.remove("d-none");
  form.reset();
});

d-none é a classe utilitária do Bootstrap para display: none — o JavaScript só remove essa classe (classList.remove) quando o formulário é enviado, revelando o alerta que já estava no HTML o tempo todo, só escondido.

Passo 8 — Rodapé com ano dinâmico

index.html
<footer class="bg-dark text-white text-center py-4">
  <p class="mb-0">&copy; <span id="anoAtual"></span> Amigo Fiel Pet Shop. Todos os direitos reservados.</p>
</footer>
script.js
document.querySelector("#anoAtual").textContent = new Date().getFullYear();

Um detalhe pequeno, mas que evita um rodapé com "2024" esquecido para sempre — o ano se atualiza sozinho, todo ano, sem precisar editar o HTML de novo.

Passo 9 — Botão "voltar ao topo"

Depois do </footer>, adicione um botão fixo que só aparece depois de rolar a página:

index.html
<button id="btnTopo" class="btn btn-success rounded-circle d-none"
  style="position: fixed; bottom: 20px; right: 20px; width: 50px; height: 50px;">
  ↑
</button>
script.js
const btnTopo = document.querySelector("#btnTopo");

window.addEventListener("scroll", () => {
  if (window.scrollY > 400) {
    btnTopo.classList.remove("d-none");
  } else {
    btnTopo.classList.add("d-none");
  }
});

btnTopo.addEventListener("click", () => {
  window.scrollTo({ top: 0, behavior: "smooth" });
});

O evento scroll dispara a cada pixel rolado — por isso a condição window.scrollY > 400 é o que decide mostrar ou esconder o botão, em vez de ele aparecer de uma vez só no início.

Checklist final

  • A navbar colapsa num botão hambúrguer quando a janela é estreita
  • O hero mostra o degradê verde-azul, não a cor sólida padrão do Bootstrap
  • Os três cards de serviço ficam em 3 colunas no desktop e empilhados no celular
  • Enviar o formulário de contato mostra a mensagem de sucesso com o nome do pet digitado
  • O rodapé mostra o ano atual corretamente, sem estar escrito à mão
  • Rolar a página para baixo faz o botão "↑" aparecer; clicar nele volta suavemente ao topo

Desafio extra

Escolha pelo menos um:

  1. Troque os emojis dos cards de serviço por ícones do Bootstrap Icons (outra biblioteca via CDN, separada do Bootstrap principal).
  2. Adicione uma quarta seção "Galeria" com um row row-cols-2 row-cols-md-4 de fotos (pode usar imagens de placeholder, como https://placehold.co/300x300).
  3. Valide o campo "Nome do pet" para não aceitar só números, usando pattern no HTML e uma segunda checagem em JavaScript antes de mostrar a mensagem de sucesso.
