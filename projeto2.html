Lista de Tarefas com Filtros

HTML CSS JavaScript Bootstrap

Um gerenciador de tarefas de verdade: adicionar, concluir, remover, filtrar por status — tudo guardado no navegador, sobrevivendo a um recarregamento de página.

Pré-requisitos

Além do Projeto 1, os módulos de JavaScript Intermediário (DOM, eventos, JSON e localStorage) — este projeto é essencialmente a prática guiada daquele material inteiro.

Essas duas classes não existem no Bootstrap — são exatamente o tipo de ajuste pequeno e específico que fica no seu próprio CSS, por cima do framework.

Passo 4 — Estado e renderização

Toda lista de tarefas precisa de um lugar para guardar os dados antes de desenhar qualquer coisa na tela. Comece script.js assim:

script.js
let tarefas = [];
let filtroAtual = "todas";

function renderizar() {
  const lista = document.querySelector("#listaTarefas");
  const mensagemVazia = document.querySelector("#mensagemVazia");

  const tarefasFiltradas = tarefas.filter((tarefa) => {
    if (filtroAtual === "pendentes") return !tarefa.concluida;
    if (filtroAtual === "concluidas") return tarefa.concluida;
    return true; // "todas"
  });

  lista.innerHTML = "";

  tarefasFiltradas.forEach((tarefa) => {
    const item = document.createElement("li");
    item.className = "list-group-item d-flex justify-content-between align-items-center";
    item.innerHTML = `
      <span class="${tarefa.concluida ? "tarefa-concluida" : ""}">${tarefa.texto}</span>
      <span>
        <button class="btn btn-sm btn-outline-success btn-concluir" data-id="${tarefa.id}">✓</button>
        <button class="btn btn-sm btn-outline-danger btn-remover" data-id="${tarefa.id}">✕</button>
      </span>
    `;
    lista.appendChild(item);
  });

  mensagemVazia.classList.toggle("d-none", tarefasFiltradas.length > 0);
}

renderizar();

Cada tarefa vai ser um objeto { id, texto, concluida }. A função renderizar() apaga a lista inteira (lista.innerHTML = "") e a reconstrói do zero a cada chamada — mais simples de raciocinar do que tentar atualizar só o item que mudou, e rápido o suficiente para uma lista de tarefas pessoal.

Passo 5 — Adicionar tarefa

script.js
const formNovaTarefa = document.querySelector("#formNovaTarefa");
const inputTarefa = document.querySelector("#inputTarefa");

formNovaTarefa.addEventListener("submit", (evento) => {
  evento.preventDefault();

  const texto = inputTarefa.value.trim();
  if (texto === "") return;

  tarefas.push({
    id: Date.now(),      // forma simples de gerar um id único
    texto: texto,
    concluida: false
  });

  inputTarefa.value = "";
  renderizar();
});

Date.now() retorna o número de milissegundos desde 1970 — como duas tarefas quase nunca são criadas no mesmo milissegundo exato, funciona bem como id único para um projeto deste tamanho.

Salve e teste: digite algo no campo, clique em "Adicionar" (ou aperte Enter) — a tarefa deve aparecer na lista.

Passo 6 — Concluir e remover

Os botões ✓ e ✕ são recriados toda vez que renderizar() roda — por isso não dá para ligar um addEventListener direto neles uma única vez. A solução é delegação de eventos: escutar o clique no <ul> (que sempre existe) e descobrir, a partir dali, em qual botão o clique realmente aconteceu.

script.js
const listaTarefas = document.querySelector("#listaTarefas");

listaTarefas.addEventListener("click", (evento) => {
  const botaoConcluir = evento.target.closest(".btn-concluir");
  const botaoRemover = evento.target.closest(".btn-remover");

  if (botaoConcluir) {
    const id = Number(botaoConcluir.dataset.id);
    const tarefa = tarefas.find((t) => t.id === id);
    tarefa.concluida = !tarefa.concluida;
    renderizar();
  }

  if (botaoRemover) {
    const id = Number(botaoRemover.dataset.id);
    tarefas = tarefas.filter((t) => t.id !== id);
    renderizar();
  }
});

evento.target.closest(".btn-concluir") funciona mesmo se o clique acontecer no ícone dentro do botão, não só no botão em si — closest sobe pela árvore do DOM até achar o elemento mais próximo que casa com o seletor.

Passo 7 — Filtros

script.js
const botoesFiltro = document.querySelectorAll(".filtro");

botoesFiltro.forEach((botao) => {
  botao.addEventListener("click", () => {
    filtroAtual = botao.dataset.filtro;

    botoesFiltro.forEach((b) => b.classList.remove("ativo"));
    botao.classList.add("ativo");

    renderizar();
  });
});

Repare que renderizar() já sabia filtrar (Passo 4) — este passo só adiciona a interface para escolher o filtro, mudando a variável filtroAtual e chamando a mesma função de novo.

Passo 8 — Contador de pendentes

Dentro de renderizar(), logo antes do fechamento da função, adicione:

script.js
function renderizar() {
  // ... todo o código que já existe ...

  const pendentes = tarefas.filter((t) => !t.concluida).length;
  document.querySelector("#contadorPendentes").textContent = pendentes;
}

Esse contador conta sempre sobre tarefas (a lista completa), não sobre tarefasFiltradas — ele deve mostrar quantas estão pendentes no total, independente do filtro selecionado na tela.

Passo 9 — Persistência com localStorage

Sem isso, tudo some ao recarregar a página. Duas peças: salvar sempre que algo mudar, e carregar ao abrir.

script.js
function salvar() {
  localStorage.setItem("tarefas", JSON.stringify(tarefas));
}

function carregar() {
  const salvas = localStorage.getItem("tarefas");
  tarefas = salvas ? JSON.parse(salvas) : [];
}

Agora chame salvar() em todo lugar que modifica o array — depois do push (adicionar), depois do toggle de concluida, e depois do filter (remover). A forma mais simples é chamar dentro da própria renderizar(), já que ela roda depois de toda mudança:

function renderizar() {
  salvar();   // primeira linha da função

  // ... resto do código que já existe ...
}

E troque a linha final do arquivo (que hoje é só renderizar();) por:

carregar();
renderizar();
Teste isto

Adicione algumas tarefas, conclua uma, e recarregue a página (F5). Tudo deve continuar exatamente como estava.

Checklist final

  • Adicionar uma tarefa pelo campo de texto funciona, e o campo limpa sozinho depois
  • Clicar em ✓ risca o texto da tarefa; clicar de novo desfaz
  • Clicar em ✕ remove a tarefa da lista imediatamente
  • Os três botões de filtro mostram só as tarefas certas, e o botão ativo fica destacado
  • O número ao lado de "Minhas Tarefas" mostra a contagem de pendentes, sempre atualizada
  • Recarregar a página (F5) não apaga as tarefas

Desafio extra

  1. Adicione um botão "Limpar concluídas" que remove de uma vez todas as tarefas marcadas como concluídas.
  2. Permita editar o texto de uma tarefa existente com duplo clique nela (dica: troque o <span> por um <input> temporário).
  3. Adicione um campo de prioridade (Baixa/Média/Alta) na criação da tarefa, mostrando um badge colorido correspondente ao lado do texto.
